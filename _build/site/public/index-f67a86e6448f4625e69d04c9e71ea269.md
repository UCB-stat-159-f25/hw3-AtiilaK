## Homework 3 – From Notebooks to Research Packages, Part II

[![Review Assignment Due Date](https://classroom.github.com/assets/deadline-readme-button-22041afd0340ce965d47ae6ef1cefeee28c7c493a6346c4f15d667ab976d596c.svg)](https://classroom.github.com/a/wOo27OxG)

This repository contains my HW3 submission for STAT 159/259: From Notebooks to Research Packages, Part II. It extends the HW2 LIGO GW150914 analysis into an installable package with tests and a minimal documentation site. I reorganized inputs and outputs into `data/`, `figures/`, and `audio/`, created `utils.py` (whiten, reqshift, write_wavfile, plotting helper), added unit tests for `readligo.py` and `utils.py` runnable via `pytest ligotools`, and defined packaging with `pyproject.toml`. A Binder badge enables live runs, and a MyST site builds locally and deploys to GitHub Pages with GitHub Actions. The site can be accessed via: https://ucb-stat-159-f25.github.io/hw3-AtiilaK/.

_This repository is public so that Binder can find it. All code and data is based on the original [LIGO Center for Open Science Tutorial Repository](https://github.com/losc-tutorial/LOSC_Event_tutorial). This repository is a class exercise that restructures the original LIGO code for improved reproducibility, as a homework assignment for the [Fall 2025 installment of UC Berkeley's Stat 159/259 course, _Reproducible and Collaborative Data Science](https://ucb-stat-159-f25.github.io/site/). Authorship of the original analysis code rests with the LIGO collaboration._

## What’s here
- `ligotools/`: installable package (whiten, reqshift, write_wavfile, plotting utils)
- `LOSC_Event_tutorial.ipynb`: main analysis notebook using `ligotools`
- `tests/`: pytest unit tests for `readligo.py` and `utils.py`
